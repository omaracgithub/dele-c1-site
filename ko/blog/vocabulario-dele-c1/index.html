DELE C1을 위한 핵심 어휘

업데이트: 2026년 6월

C1 수준은 광범위하고 정확하며 다양한 어휘를 요구합니다. 단어를 아는 것만으로는 충분하지 않습니다: 적절한 맥락에서, 올바른 레지스터로, 적절한 콜로케이션과 함께 사용하는 방법을 알아야 합니다. 이 기사는 DELE C1에서 가장 자주 사용되는 어휘 분야, 고급 연결어, 관용구 및 레지스터에 대한 핵심 정보를 제공합니다.

필수 어휘 분야

정치와 사회

  • 법률, 규정, 법령, 수정안, 공포하다
  • 시민권, 투표, 의석, 연합, 임기
  • 불평등, 사회적 격차, 소외, 통합
  • 공공 정책, 복지, 보조금, 세금
  • 이민, 수용, 정착, 합법화

환경

  • 지속 가능성, 생태 발자국, 배출, 폐기물
  • 재생 가능 에너지, 에너지 전환, 탈탄소화
  • 생물 다양성, 생태계, 삼림 파괴, 사막화
  • 폐기물, 재활용, 순환 경제, 노후화
  • 기후 변화, 지구 온난화, 온실 효과

기술과 커뮤니케이션

  • 인공지능, 알고리즘, 자동화, 디지털화
  • 사이버 보안, 프라이버시, 개인 데이터, 암호화
  • 디지털 격차, 디지털 리터러시, 연결성
  • 소셜 미디어, 잘못된 정보, 바이럴화, 인플루언서
  • 혁신, 기업가 정신, 스타트업, 확장성

건강과 웰빙

  • 보건 시스템, 1차 진료, 전문의, 의뢰하다
  • 예방, 진단, 치료, 예후
  • 정신 건강, 정서적 웰빙, 스트레스, 불안
  • 건강한 습관, 앉아있는 생활, 영양, 중독
  • 임상 연구, 시험, 백신, 팬데믹

교육과 문화

  • 교육 시스템, 커리큘럼, 역량, 평가
  • 지속 교육, 훈련, 자격증, 인증
  • 문화유산, 정체성, 다양성, 다문화성
  • 출판 산업, 보급, 후원, 문화 보조금
  • 교육 격차, 중퇴, 포용, 형평성

경제와 노동

  • 노동 시장, 실업률, 불안정, 조화
  • 생산성, 경쟁력, 인플레이션, 경기 침체
  • 재택근무, 유연성, 근무 시간, 협약
  • 기업가 정신, 자영업, 투자, 수익성
  • 세계화, 이전, 외부 무역, 관세

고급 담화 연결어

담화 조직

  • 관한 / 관련하여 / 관련해서
  • 이런 말을 하면서 / 앞서 언급한 바와 같이 / 고려할 때
  • 다음에 / 이어서 / 즉시

추가 및 강조

  • 더욱이 / 더욱 / 심지어
  • 주목할 점은 / 강조할 필요가 있다 / 언급할 가치가 있다
  • 헛된 것이 아니다 / 사실 / 실제로

대조 및 양보

  • 비록 / ~일지라도 / ~에도 불구하고
  • 그럼에도 불구하고 / 그럼에도 / 어떻게든
  • 멀리서 / 대신에 / 맞서서

원인과 결과

  • 덕분에 / ~의 결과로 / ~때문에
  • 그로 인해 (+subj.) / 이유는 / 원인은
  • 이는 ~로 이어진다 / 이는 ~로 귀결된다 / 이는 ~을 초래한다

재진술 및 예시

  • 즉 / 다시 말해 / 다른 말로 하면
  • 예를 들어 / 구체적으로 / 가령
  • 예시로 삼다 / 언급하기에 충분하다 / 샘플로 제공하다

자주 사용되는 관용구

DELE C1에서는 이해 텍스트와 답변 옵션 모두에서 관용구를 자주 찾을 수 있습니다:

  • 알고 있다: 어떤 것에 대해 정보를 가지고 있다
  • 당연하게 여기다: 의심 없이 어떤 것을 가정하다
  • 명백히 하다: 분명히 보여주다
  • 강조하다: 강조하다
  • 실행하다: 수행하다
  • 고려하다: 고려하다
  • 대체로: 일반적으로, 세부 사항 없이
  • ~하는 한: ~하는 동안, ~하는 경우에
  • 결국: 시간이 지나면서, 장기적으로
  • 이익을 얻다: 활용하다
  • 위험에 처하다: 위험에 처하다
  • 유발하다: 초래하다, 발생시키다
  • 정보를 퍼뜨리다: 정보를 전파하다, 반복하다
  • 기초를 다지다: 기초를 세우다
  • 무시하다: 무시하다, 주의를 기울이지 않다

레지스터의 차이

DELE C1은 맥락에 맞게 레지스터를 조정하는 능력을 평가합니다. 비공식적 레지스터와 공식적 레지스터 간의 동등성을 아래에서 확인하세요:

자주 사용되는 콜로케이션

콜로케이션은 일반적인 단어 조합입니다. 이를 아는 것은 자연스러움을 제공합니다:

  • 조치를 취하다 / 결정을 내리다 / 책임을 지다
  • 문제를 제기하다 / 문제를 다루다 / 갈등을 해결하다
  • 합의에 도달하다 / 합의에 이르다 / 목표를 달성하다
  • 역할을 수행하다 / 영향을 미치다 / 기능을 수행하다
  • 관심을 불러일으키다 / 논란을 일으키다 / 기대를 불러일으키다

어휘를 확장하기 위한 팁

  1. 양질의 신문 읽기: El País, El Mundo, La Vanguardia, BBC Mundo
  2. 맥락에서 메모하기: 단어를 따로 적지 말고 전체 문장을 적으세요
  3. 간격 반복 사용하기: 새로운 어휘를 점차적으로 복습하세요
  4. 적극적으로 연습하기: 새로운 단어를 글쓰기와 대화에서 사용하세요
  5. 분야별로 그룹화하기: 어휘를 주제별로 정리하세요, 알파벳 순이 아닌

또한 읽어보세요: 독해 전략에서 맥락에서의 어휘에 대한 더 많은 팁을 찾을 수 있습니다.
